# Supplements – Shopify theme

Health & wellbeing Shopify theme, based on Shopify's [Dawn](https://github.com/Shopify/dawn) theme.

## Connect to Shopify
1. Shopify Admin → **Online Store → Themes**
2. **Add theme → Connect from GitHub**
3. Choose this repo (`Supplements-`) and the `main` branch
4. Preview, then **Publish** when ready

Changes pushed to `main` sync to the theme automatically (and edits made in the theme editor are committed back here).
