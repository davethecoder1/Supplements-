# Electrolife – Shopify theme

Theme for the Electrolife store (high-sodium electrolyte drink mix). Based on Shopify's Dawn theme, with custom `el-*` sections (hero, nutrition, flavours, comparison, subscribe, quiz, FAQ, reviews) and `assets/electrolife.css`.

Copied from the live theme **Electrolife v1.1 (collections)**.

## Connect to Shopify
1. Shopify Admin → **Online Store → Themes**
2. **Add theme → Connect from GitHub**
3. Choose this repo (`Supplements-`) and the `main` branch
4. Preview it, then **Publish** when ready

Pushes to `main` sync to the connected theme, and edits made in the theme editor are committed back here.
